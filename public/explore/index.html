Explore

Run mctop against a server to open the full-screen client. Move through its tools, resources, and prompts, fill a tool's arguments in a schema-driven form, run it, and read the result laid out as fields and tables, not raw JSON.

example
❯ mctop uvx mcp-server-time connected

tools 2

get_current_time

convert_time

resources 0

prompts 0

get_current_time

Get the current time in a given timezone

arguments

timezone* string

❯ enter to call

enter open · / search · tab section · ? keys

The result view formats values by type: dates, yes/no, and grouped numbers. Nested objects become sections, and arrays of records become selectable tables. Press t for raw JSON, T for the protocol trace, y to copy.
